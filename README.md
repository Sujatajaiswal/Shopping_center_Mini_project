A simple, multi-page shopping center website built using HTML and CSS. This project simulates a basic e-commerce storefront where users can browse clothing items and navigate through product pages.

 Features
 
 Homepage with branding and navigation

 Clothing gallery with multiple product images

 Multiple HTML pages (e.g., home, product listing, product details)

 Clean UI layout built with HTML & CSS

 Internal page navigation

 Static and lightweight project — ideal for practice & learning web structure

Technologies Used

HTML5

CSS3

Image assets (.jpg, .png)
